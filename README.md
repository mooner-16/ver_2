# IRON OATH — 중세 기사 1인칭 멀티플레이 칼싸움

브라우저에서 즐기는 1인칭 기사 대전입니다. Node.js 서버 하나만 켜면 친구들이 주소로 접속해서 같이 싸울 수 있어요.

## 실행 방법

1. [Node.js](https://nodejs.org) 18 이상 설치
2. 이 폴더에서 터미널을 열고:

```bash
npm install
npm start
```

서버가 뜨면 접속 주소가 출력됩니다.

- 내 컴퓨터: `http://localhost:3000`
- 같은 와이파이/LAN의 친구: 출력된 `http://192.168.x.x:3000` 주소

포트나 최대 인원을 바꾸려면:

```bash
PORT=4000 MAX_PLAYERS=24 npm start      # Windows PowerShell: $env:PORT=4000; npm start
```

## 인터넷 친구와 함께 하려면

- **가장 쉬운 방법**: 서버를 켠 뒤 터널링 도구로 3000번 포트를 공개합니다. (예: `cloudflared tunnel --url http://localhost:3000`, `ngrok http 3000`) 출력된 https 주소를 친구에게 보내면 됩니다. https 주소에서는 WebSocket도 자동으로 wss로 연결됩니다.
- **공유기 포트포워딩**: 공유기에서 3000번을 이 컴퓨터로 포워딩하고 `http://공인IP:3000` 공유
- **클라우드 배포**: Render, Railway, Fly.io 같은 곳에 이 폴더를 올리고 시작 명령을 `npm start`로 지정 (PORT 환경변수를 자동으로 읽습니다)

## 조작법

| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 시점 |
| Space | 점프 |
| 좌클릭 | 공격 |
| 우클릭 (누르고 있기) | 방어 — 정면 공격 피해 감소, 이동 느려짐 |
| Tab | 점수판 |

공격하면 방어 자세가 풀리고, 정면(약 ±50°) 사거리 안의 적만 맞습니다. 방어는 적이 내 정면에 있을 때만 통합니다.

## 기사 능력치

| 기사 | 체력 | 속도 | 공격력 | 공격 간격 | 사거리 | 방어 감소 |
|---|---|---|---|---|---|---|
| 기사 | 100 | 5.2 | 22 | 0.70s | 2.6m | 60% |
| 대검 전사 | 120 | 4.2 | 40 | 1.20s | 3.2m | 40% |
| 결투가 | 80 | 6.4 | 13 | 0.38s | 2.3m | 35% |
| 방패 기사 | 150 | 3.8 | 17 | 0.85s | 2.3m | 85% |

기사를 추가하거나 능력치를 바꾸려면 `classes.js`만 수정하면 서버와 클라이언트(선택 화면 포함)에 모두 반영됩니다.

## 구조

```
server.js        WebSocket 서버 (명중/체력/쿨다운/부활 판정은 전부 서버가 결정)
classes.js       기사 능력치와 맵 설정 (서버·클라이언트 공용)
public/          index.html(UI), game.js(Three.js 클라이언트)
test.mjs         서버 전투 로직 자동 테스트 (npm test)
```
